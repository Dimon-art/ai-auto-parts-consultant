# AI Auto Parts Consultant

## Что это

Локальный AI-сервис для подбора автозапчастей по автомобилю, году, двигателю и запросу детали.

Пользователь выбирает автомобиль и деталь, сервис ищет подходящие позиции по реальным связям совместимости (fitment), а AI объясняет найденный вариант простым языком.

Репозиторий: https://github.com/Dimon-art/ai-auto-parts-consultant

## MVP Demo v0.1

Это демонстрационная версия для локального запуска, а не коммерческий каталог.

## Что работает

- выбор автомобиля: Марка → Модель → Год → Двигатель;
- поиск запчасти по запросу детали;
- fitment-поиск (реальные связи совместимости);
- карточка результата с OEM, ценой и совместимостью;
- AI-объяснение найденного варианта;
- предупреждение о предварительной совместимости и необходимости проверки VIN;
- запуск в Docker с сохранением данных (persistent volume).

## Архитектура

- Frontend: HTML, CSS, vanilla JavaScript (без внешних библиотек);
- Backend: FastAPI (Python);
- База данных: SQLite;
- AI-ответ: через существующий `ai_assistant.py`;
- Запуск приложения: `uvicorn web_app:app`, порт 8023;
- Контейнер: `ai-auto-parts-consultant`;
- Хранение данных: SQLite в Docker persistent volume.

## Запуск

Перейдите в каталог проекта и запустите контейнер:

```bash
cd C:\Users\user\ai-auto-parts-consultant
docker compose up -d
```

Не используйте `docker compose down -v` — эта команда удалит данные из volume.

## Проверка Docker

```bash
docker compose ps
```

Ожидаемый результат:

```
ai-auto-parts-consultant   Up   0.0.0.0:8023->8023/tcp
```

## Открытие в браузере

Откройте: http://localhost:8023

localhost доступен только на компьютере, где запущен Docker.

## Что пока не подключено

- «Сравнить» — пока не подключена к backend;
- «Сохранить» — пока не подключена к backend;
- «Проверить по VIN» — пока открывает демонстрационный интерфейс, полноценная VIN-проверка не подключена;
- каталог запчастей демонстрационный и содержит 6 позиций;
- fitment-данные пока ограничены 4 связями;
- внешний доступ из интернета не настроен.

## Данные

Данные хранятся в SQLite. Проверенное состояние базы:

- parts = 6
- catalogs = 19
- makes = 5
- models = 21
- generations = 274
- engines = 1794
- fitments = 4

База демонстрационная и не является полноценным коммерческим каталогом.

## Persistent Docker volume

- volume: `parts_data`;
- путь базы внутри контейнера: `/app/data/parts_catalogs.db`;
- данные сохраняются между перезапусками контейнера;
- не выполняйте `docker compose down -v`, чтобы не потерять данные.
