# AI Auto Parts Consultant

Локальный Python MVP для подбора автозапчастей по автомобилю, году, двигателю и описанию детали.

## Что умеет

- принимает марку, модель и год автомобиля;
- принимает двигатель (необязательно);
- принимает описание нужной детали;
- ищет совместимые позиции в локальном демо-каталоге;
- показывает категорию, OEM, цену и примечание по совместимости;
- если совпадение не найдено, просит уточнить данные;
- позволяет выполнить новый подбор без перезапуска программы.

## Запуск

```bash
python app.py
```

Каталог находится в `catalog.json`. Это демонстрационные данные, не источник гарантированной совместимости для реального заказа.
