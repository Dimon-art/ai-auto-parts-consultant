# AI Auto Parts Consultant — Project Brief

## 1. Проект

**AI Auto Parts Consultant** — демонстрационный AI-сервис для подбора автозапчастей по автомобилю, двигателю и названию детали.

Версия:

**MVP Demo v0.1**

---

## 2. Цель MVP

Показать полный рабочий сценарий:

1. Пользователь выбирает автомобиль.
2. Выбирает год и двигатель.
3. Указывает необходимую деталь.
4. Сервис получает данные из локально сохранённого каталога PartsAPI.
5. Backend возвращает найденные варианты.
6. AI формирует понятное объяснение результата.
7. Frontend отображает карточки найденных запчастей.

---

## 3. Демонстрационный сценарий

Основной сценарий демонстрации:

**Volkswagen → Golf → 2018 → 1.0L TSI 6MT FWD (110 HP) → Масляный фильтр**

Результат должен показывать реальные сохранённые данные PartsAPI.

Пример первой позиции:

- Артикул: `L40635`
- Бренд: `1A FIRST AUTOMOTIVE`
- OEM: `VAG: 04E 115 561...`
- Группа: `Масляный фильтр`
- Двигатель: `1.0L TSI 6MT FWD (110 HP)`

12. PartsAPI

В проекте используется PartsAPI как источник данных каталога автозапчастей.

На этапе MVP данные PartsAPI были получены заранее и сохранены локально.

Для демонстрационного автомобиля:

CAR_ID = 124239

Для группы:

STR_ID = 100470

Связь:

CAR_ID
   ↓
STR_ID
   ↓
PartsAPI article

В локальной базе сохранено:

partsapi_articles: 10
partsapi_fitments: 10

Новые запросы к PartsAPI во время обычного демонстрационного сценария не выполняются.

23. Ограничения MVP

MVP является демонстрационной версией продукта.

Основные данные PartsAPI сохранены локально.

Текущий сценарий не является полноценным онлайн-каталогом с динамическим обновлением всех данных.

Подтверждение применяемости каждой отдельной статьи через getApplicability в текущую версию не включено.

Перед реальной покупкой необходимо дополнительно проверять:

VIN;
OEM;
размеры;
