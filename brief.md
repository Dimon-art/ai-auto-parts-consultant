# AI Auto Parts Consultant — UI Brief

## Цель

Сделать современный профессиональный интерфейс для AI-сервиса подбора автозапчастей.

Это не обычный каталог. Основной сценарий:
пользователь выбирает автомобиль, двигатель и нужную деталь, после чего AI помогает подобрать подходящие варианты.

## Backend менять нельзя

Не изменять:

- web_app.py backend-логику
- POST /query
- модель Query
- поля:
  - make
  - model
  - year
  - engine
  - part_request
- структуру JSON-ответа API
- db.py
- ai_assistant.py

API должен продолжать работать как сейчас.

## Frontend

Использовать только:

- HTML
- CSS
- чистый JavaScript

Без:

- React
- Vue
- Bootstrap
- Tailwind
- CDN
- внешних библиотек

Основные frontend-файлы:

- static/index.html
- static/style.css
- static/app.js

## UX

Сделать интерфейс в стиле профессионального AI-консультанта.

Название:

AI Auto Parts Consultant

Подзаголовок:

Умный подбор автозапчастей

Главный заголовок:

Подберём подходящую запчасть поможет AI

Описание:

Укажите автомобиль и деталь — AI объяснит результат и покажет подходящие варианты.

## Автомобиль

Пользователь не должен каждый раз вручную вводить марку и модель.

Нужен удобный выбор автомобиля:

Марка → Модель → Год → Двигатель

Для MVP можно использовать выпадающие списки / datalist.

Важно:
текущие значения должны всё равно отправляться в API в существующих полях:

make
model
year
engine

## Форма

Поля:

- Марка
- Модель
- Год
- Двигатель
- Какая деталь нужна?

Кнопка:

🔎 Найти запчасть

Placeholder детали:

Например: масляный фильтр, тормозные колодки, свечи

## Валидация

Обязательные:

- марка
- модель
- год
- деталь

Двигатель необязателен.

Год:

1950 ... текущий год + 1

При ошибке:

- красная рамка
- понятное сообщение
- запрос на API не отправлять

## Результат

Показывать:

- количество найденных вариантов
- название детали
- OEM
- категорию
- автомобиль
- двигатель
- цену
- информацию о совместимости
- ответ AI

Показывать максимум 5 деталей.

Не утверждать совместимость на 100%, если API этого явно не сообщает.

Использовать формулировки:

- предварительная совместимость
- требуется проверка VIN
- подтвердите совместимость по VIN

## AI-диалог

Результат должен визуально выглядеть как диалог:

Пользователь:
Нужен(на): масляный фильтр

AI:
Ответ консультанта

Во время запроса:

Проверяю совместимость и ищу подходящие варианты…

Кнопка:

Поиск…

После ответа кнопка снова:

🔎 Найти запчасть

## Если деталей нет

Показать:

Точного совпадения пока не найдено. Проверьте марку, модель, год, двигатель или уточните название детали. Для точного подбора используйте VIN.

## Если AI-ответ пустой

Но детали найдены:

Я нашёл подходящие варианты. Перед заказом рекомендую подтвердить совместимость по VIN.

## Ошибка сервера

Не показывать пользователю технические ошибки.

Показывать:

Не удалось получить ответ сервера. Попробуйте ещё раз через минуту.

Оригинальную ошибку можно вывести через console.error().

## VIN

Кнопка "Проверить по VIN" открывает модальное окно.

Пока VIN не отправлять на backend.

После проверки показать:

VIN-подбор будет подключён к каталогу в следующей версии.

## Безопасность

Сохранить функцию:

escapeHtml(text)

Использовать её при выводе данных API.

Корректно обрабатывать AI-тексты с:

- реальными переносами строк
- \n
- \r\n
