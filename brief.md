# AI Auto Parts Consultant — Product & Technical Brief

Версия: MVP Demo v0.1
Последний commit: 086458d — «MVP Demo v0.1: add fitment-based part search»
Репозиторий: https://github.com/Dimon-art/ai-auto-parts-consultant

## 1. Продукт

AI Auto Parts Consultant — локальный AI-сервис для подбора автозапчастей.

Пользователь указывает автомобиль (марку, модель, год), двигатель и нужную деталь. Сервис ищет подходящие позиции по реальным связям совместимости (fitment) и показывает результат. AI дополнительно объясняет найденный вариант простым языком.

Это не обычный каталог: главная ценность — помощь в подборе и понятное объяснение результата.

## 2. Цель MVP

Показать рабочий сквозной сценарий подбора запчасти на демонстрационных данных:

- выбор автомобиля и детали;
- поиск по связям fitment;
- карточка результата с OEM, ценой и совместимостью;
- AI-объяснение результата;
- честное предупреждение о том, что совместимость предварительная и требует проверки по VIN.

MVP предназначен для локального запуска и демонстрации заказчику. Это не коммерческий каталог.

## 3. Основной пользовательский сценарий

Контрольный сценарий:

Volkswagen → Golf → 2018 → 1.4 TSI → Масляный фильтр → «Найти запчасть»

Результат контрольного сценария:

- найденных вариантов: 1
- название: Масляный фильтр
- OEM: 06L115562B
- автомобиль: Volkswagen Golf 2013–2020
- двигатель: 1.4 TSI, 1.5 TSI
- цена: 12.5 EUR
- совместимость: предварительная совместимость, требуется проверка VIN
- AI формирует объяснение результата.

## 4. Целевая UX-логика

- пользователь не вводит всё вручную, а выбирает автомобиль по цепочке: Марка → Модель → Год → Двигатель;
- двигатель необязателен;
- поле «Какая деталь нужна?» с примером-подсказкой (масляный фильтр, тормозные колодки, свечи);
- категории в боковой панели помогают быстро подставить тип детали;
- результат оформлен как диалог: запрос пользователя и ответ AI;
- максимум 5 деталей в результате;
- совместимость нельзя утверждать на 100%; используются формулировки: предварительная совместимость, требуется проверка VIN, подтвердите совместимость по VIN.

Категории в боковой панели:

- Масла и жидкости
- Фильтры
- Тормозная система
- Подвеска
- Двигатель
- Электрика
- Кузовные детали

## 5. Frontend

- HTML, CSS, vanilla JavaScript (без React/Vue/Bootstrap/Tailwind/CDN и внешних библиотек);
- стиль: профессиональный automotive AI-сервис; цвета — белый, глубокий зелёный, серый;
- современный чистый и адаптивный интерфейс;
- основные элементы: бренд «AI Auto Parts Consultant», подзаголовок «Умный подбор автозапчастей», выбор марки/модели/года/двигателя, запрос детали, категории, результат поиска, AI-объяснение.

Текущий UI считается рабочей версией MVP и не требует полного редизайна.

Отдельно зафиксировано: утверждён фоновый визуал стартовой страницы с автомобилем/автосервисом. Его подключение — отдельная следующая задача и НЕ входит в MVP Demo v0.1.

## 6. Backend

- FastAPI на Python;
- запуск через `uvicorn web_app:app`, порт 8023;
- основной эндпоинт `POST /query` принимает автомобиль, двигатель и запрос детали, возвращает найденные позиции и AI-объяснение.

## 7. Data / SQLite

- данные хранятся в SQLite;
- в Docker используется persistent volume `parts_data`;
- путь базы внутри контейнера: `/app/data/parts_catalogs.db`.

Проверенное состояние базы в Docker volume:

- parts = 6
- catalogs = 19
- makes = 5
- models = 21
- generations = 274
- engines = 1794
- fitments = 4

База запчастей демонстрационная. Это не полноценный коммерческий каталог.

## 8. Fitment

В MVP добавлен поиск через реальные связи fitment.

Цепочка связей:

part → fitment → engine → generation → model → make

Для контрольного автомобиля Volkswagen Golf 2018 / 1.4 TSI есть реальные fitment-связи.

100% совместимость утверждать нельзя. Используются формулировки: предварительная совместимость, требуется проверка VIN, подтвердите совместимость по VIN.

## 9. AI

AI-ответ работает через существующий `ai_assistant.py` и объясняет найденный вариант.

Пример диалога:

- Пользователь: «Нужен(на): масляный фильтр»
- AI: объясняет найденный вариант.

Тексты для особых случаев:

- пустой AI-ответ, но детали найдены: «Я нашёл подходящие варианты. Перед заказом рекомендую подтвердить совместимость по VIN.»
- деталей нет: «Точного совпадения пока не найдено. Проверьте марку, модель, год, двигатель или уточните название детали. Для точного подбора используйте VIN.»
- ошибка сервера: «Не удалось получить ответ сервера. Попробуйте ещё раз через минуту.»

## 10. Результат

В карточке результата показываются:

- количество найденных вариантов;
- название детали;
- OEM;
- категория;
- автомобиль;
- двигатель;
- цена;
- информация о совместимости (предварительная, с рекомендацией проверить VIN);
- AI-объяснение.

Кнопки в карточке: «Сравнить», «Сохранить», «Проверить по VIN».

## 11. Ограничения MVP

- «Сравнить» пока не подключена к backend;
- «Сохранить» пока не подключена к backend;
- «Проверить по VIN» пока открывает демонстрационный интерфейс; полноценная VIN-проверка не подключена;
- каталог запчастей демонстрационный и содержит 6 позиций;
- fitment-данные пока ограничены 4 связями;
- внешний доступ из интернета не настроен;
- localhost доступен только на компьютере, где запущен Docker.
